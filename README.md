# Inventory & Warehouse Reorder MCP

An MCP server built using **NitroStack SDK and MongoDB** to manage inventory across multiple warehouse locations, automate stock reordering, process transfers, and reconcile physical stock counts.

## Features

* Multi-location stock tracking
* Automatic low-stock reorder detection
* Supplier and purchase order management
* Warehouse stock transfers
* Inbound stock receiving
* Cycle-count reconciliation
* Inventory valuation and shrinkage reports

## Tech Stack

**NitroStack SDK · TypeScript · Node.js · MongoDB · Zod**

## Goal

Maintain accurate inventory across warehouses, automate reordering, and ensure safe and consistent stock updates.
